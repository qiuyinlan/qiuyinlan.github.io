前端基础 HTML CSS JavaScript 学习

前端基础 HTML CSS JavaScript 学习

从零开始的前端学习笔记整合，按知识体系重组而非课程顺序。保留原始问答形式，但合并重复内容、补充逻辑衔接，形成连贯的学习文档。

一、HTML 基础

1.1 标签与属性

标签是什么？

标签就是 HTML 里用来”标记”内容的特殊符号，就像给文字贴的便利贴，告诉浏览器该怎么显示。

基本写法：

  • 用尖括号 < > 包裹关键词，比如 <a> 或 <p>
  • 通常成对出现：<标签名> 是开始标签，</标签名> 是结束标签，把内容包在中间
  • 例如：<a href="...">这是一个链接</a>

简单说，标签就是网页的”积木”，不同标签负责搭建不同内容（标题、段落、图片等）。

属性的作用

属性写在开始标签里，用来给标签附加信息，写法是 属性名="属性值"。

常见属性举例：

  • href：给 <a> 标签指定链接地址，点哪里去
  • src：给 <img> 标签指定图片文件在哪
  • alt：给 <img> 标签指定图片加载失败时的替代文字
  • width/height：给标签指定宽高尺寸

常见缩写记忆

缩写 全称 含义
href Hypertext Reference 超文本引用，跳转目标
target Target 目标，决定链接在哪里打开
rel Relationship 关系，说明当前页面和链接页面的关系
id Identifier 标识符，给页面元素起个唯一名字
a Anchor 锚点，早期用来标记页面内跳转位置

新窗口打开链接

  • target="_blank"：在新标签页打开（_self 是在当前页面打开）
  • rel="noopener"：防止安全风险，建议加上

📌 记忆技巧：_self 就像待在现在的房间，_blank 就是去新开的房间。

1.2 列表系统

HTML 有三种列表，用途不同：

1. 无序列表（ul）

  • ul = Unordered List，没有顺序，用项目符号（圆点）
  • 适用场景：菜单、并列项

2. 有序列表（ol）

  • ol = Ordered List，有先后顺序，用数字序号
  • 适用场景：步骤、排名

3. 描述列表（dl）

  • dl = Description List（描述列表）
  • dt = Description Term（术语/名词）
  • dd = Description Details（详情/解释）
  • 适用场景：字典、词汇表、键值对展示

效果特点：

  • <dt>（术语）：显示为粗体，独占一行
  • <dd>（描述）：向右侧缩进，独占一行

📌 记忆口诀：U 无 O 有找顺序，L 是项，D 是描述，T 是词，D 是详。

嵌套列表

在 <li> 里再放一个 <ul>/<ol> 就能实现多级菜单、目录树等层级结构。

1.3 语义化标签

什么是语义标签？

语义标签不是写给”人看的样子”，而是写给机器看的含义。比如 <nav>、<article>、<header> 这些标签，直接告诉浏览器和爬虫”这块内容是什么”。

为什么用语义标签？

  1. 利于搜索引擎爬虫

    • 爬虫是”瞎子”，只读代码不看图
    • <main>、<article>、<h1> 直接告诉它”这块是核心内容”
    • 结构清晰时，搜索引擎更容易匹配搜索词，还可能生成”富摘要”

  2. 照顾视障用户

    • 屏幕阅读器靠这些标签导航
    • 读到 <nav> 就知道”这里是导航，可以跳转”
    • 全是 <div> 的话，读屏器只会当成普通盒子

  3. 代码可维护性

    • <header>、<nav>、<main> 一眼就知道是哪块
    • 多人协作或回头改代码时省很多事

常用语义标签对比

标签 用途 关键要求
<nav> 主导航（路线图） 装一组跳转链接
<section> 带标题的分章 必须有 <h2> 等标题
<div> 纯样式容器 无语义，兜底使用

⚠️ 反例提示：只是装样式、没标题、不表达主题就该用 <div> 兜底，别硬塞 <section>。

一句话总结

爬虫不是敌人，是帮你把内容送进搜索结果的搬运工——你标签写得越”名副其实”，它搬得越准，你的页面就越容易被搜到。

1.4 data-* 与 contenteditable

data- 自定义数据属性*

核心作用：把”不属于样式、不属于结构”的业务数据，直接贴在元素身上，让 JS 和 CSS 随时能取用。

典型场景：事件委托

没有 data-* 的话，只能把 id 塞进 class 或 id 里再解析字符串，又脏又容易出错。

CSS 直接使用

隐性好处：

  1. 浏览器完全忽略 data- 前缀的属性，不影响布局和渲染
  2. 在 React/Vue 里，是把组件 props 传到真实 DOM 上、又不破坏封装的正规通道

⚠️ 一个坑：dataset 读出来的永远是字符串，data-id="101" 拿到的是 "101" 不是数字 101，要算数得自己转。

contenteditable vs input

特性 input / textarea contenteditable
内容格式 纯文本 HTML 片段（富文本）
取值方式 .value .innerHTML / .innerText
高度 固定，需手动算 随内容自动撑高
样式控制 受浏览器默认样式限制 完全自由
表单提交 自动随 form 提交 需手动处理
XSS 风险 低 高，必须过滤

判断标准：

  • 用户名、密码、搜索词、手机号 → 用 input（语义好、无障碍好、移动端键盘优化好）
  • 需要加粗/斜体/插入图片/贴富文本 → 只能用 contenteditable（Notion、飞书文档、公众号后台都用这个）

一个细节：contenteditable="plaintext-only" 可以只要换行和自适应高度，但过滤掉粘贴进来的格式，行为接近 textarea。

1.5 图片与多媒体

图片 img

  • src：图片来源
  • alt：图片加载失败或屏幕阅读器场景下显示，务必填写
  • width/height：指定显示尺寸（建议只设一个，另一个按比例缩放，避免变形）

常用图片格式对比

格式 特点 适用场景

音频与视频

  • poster：视频封面图
  • <source>：多格式备选源，浏览器选第一个能播放的
  • autoplay：自动播放经常被浏览器策略拦截（尤其带声音的），一般要配合 muted 静音
  • loop：循环播放
  • preload：预加载（按需使用）

嵌入与图标

iframe 嵌入网页

  • 可以把另一个网页嵌进当前页面（如地图、视频播放器）
  • 注意：很多网站会通过 X-Frame-Options 禁止被嵌入

页面图标

Open Graph 标签（社交媒体分享卡片）

字体图标（如 Font Awesome、Material Icons）

  • 本质是字体文件，用 <i class="..."> 或 <span class="..."> 引用
  • 比图片图标更清晰、可换色

1.6 表格与表单

表格结构

  • <table>：包裹整个表格
  • <caption>：表格标题
  • <thead>：表头区
  • <tbody>：主体区
  • <tfoot>：表尾区
  • <tr>：行

合并单元格：

表单基础

  • action：提交到哪个 URL

常用输入类型

📌 移动端不同 type 会唤起不同键盘，提升输入效率（如 tel 弹数字键盘、email 弹带@的键盘）。

1.7 HTML5 进阶

head 元信息

  • <script defer>：脚本延迟执行，避免阻塞渲染
  • 视口 meta 标签：让页面按设备宽度渲染，配合 CSS 响应式实现手机端良好显示

HTML5 拖拽 API

  • 给元素加 draggable="true" 即可拖动
  • 配合 dragstart、dragover、drop 等事件实现拖放排序、文件拖入上传

canvas 与 SVG 选择

特性 canvas SVG
本质 画布（用 JS 绘制） 矢量图形标记语言
适合场景 高频动态绘制、游戏、像素级操作 静态图形、图标、图表
性能 强（适合大量图形） 较弱（图形多时慢）
可样式化 否（画完是像素） 是（可被 CSS 控制）
缩放 会模糊 无限放大不模糊

选择建议： 静态图形、图标、图表用 SVG；高频动态绘制、游戏用 canvas。

二、CSS 基础

2.1 CSS 是什么与引入方式

CSS（Cascading Style Sheets，层叠样式表）负责网页的”外观”：颜色、字体、间距、布局、动画都由它控制。

三种引入方式：

  1. 外部样式表（推荐）：<link rel="stylesheet" href="样式.css">
  2. 内部样式：<style> 写在 HTML 里
  3. 内联样式：style 属性写在标签上（优先级最高但不推荐）

基本语法：

例如 p { color: red; } 表示把所有段落文字变红。多个声明用分号分隔。

继承：部分属性会自动传给后代元素。

2.4 盒模型

每个元素都是一个”盒子”，从内到外依次是：

box-sizing 属性

  • content-box（默认）：width 只算内容区，加了 padding 盒子会变大，容易导致布局溢出
  • border-box（推荐）：width/height 包含 padding 和 border，尺寸计算更直观

margin vs padding

属性 位置 特点
padding 内容与边框之间 背景色会覆盖它
margin 元素与其他元素之间 透明，不显示背景

简写顺序（顺时针）：上 右 下 左

  • 两个值：上下 / 左右
  • 一个值：四边相同

常见坑：

  1. 垂直方向相邻 margin 会”合并”（取较大值）
  2. 子元素 margin-top 会穿透父容器，父容器加 padding 或 overflow: hidden 可以解决

2.5 display 与 position

display 常用值

值 说明
block 独占一行，像 div、p 默认就是这个，能设宽高
inline 不换行，按内容宽度排列，像 span、a，不能设宽高
inline-block 不换行，但能像块元素一样设置宽高
flex 开启 Flexbox 布局（一维）
grid 开启 Grid 布局（二维）
none 隐藏元素，且不占页面位置

position 定位方式

值 参照物 用途
static 无 默认，无特殊定位
relative 自己原本位置 微调，或作为 absolute 的参照物
absolute 最近的 position 非 static 祖先 精确定位
fixed 视口 固定不动的元素（如回到顶部按钮）
sticky 滚动阈值 滚动到阈值后吸顶

常用套路： 父元素 relative + 子元素 absolute 来精确定位。

⚠️ z-index 只在定位元素生效。

2.6 颜色、字体与文本

颜色写法

写法 说明
#ff5500 十六进制，每两位代表红 (R)、绿 (G)、蓝 (B) 的亮度
rgb(255, 85, 0) RGB 三原色，数值 0-255
rgba(255, 85, 0, 0.5) RGB + Alpha（透明度），最后一位 0-1
hsl(色相，饱和度，明度) 更符合人眼直觉的颜色模型
hsla(...) HSL + Alpha
关键词 red、blue、green 等

HSL 拆解记忆：

  • Hue（色相）：颜色本身，如红、蓝，用角度（0-360）表示
  • Saturation（饱和度）：颜色鲜艳程度，0%（灰）到 100%（鲜艳）
  • Lightness（明度）：颜色亮暗，0%（黑）到 100%（白），50% 正常
  • Alpha：透明度，0（全透）到 1（不透明）

📌 示例：hsla(0, 100%, 50%, 0.5) 表示半透明的红色。

opacity 与 rgba 的区别

  • rgba：只让当前颜色透明
  • opacity：会让整个元素（包括里面的子元素）一起变透明

颜色属性

  • color：文字颜色
  • background-color：背景色
  • border-color：边框色

📌 建议：设计时用 CSS 变量统一管理主题色，如 --main-color: #ff5500;

  • text-align：对齐（left/center/right/justify）

三、布局系统

3.1 Flex 布局基础

什么是 Flex？

Flexbox 是一维布局模型，容器设 display: flex，子元素沿主轴（默认水平）排列，自动解决”一行放几个、怎么对齐”的问题。

📌 前提：必须把父元素变成 Flex 容器。任何块级元素（如 div、section、ul）都可以。

容器常用属性

属性 说明 常用值
justify-content 主轴对齐 flex-start / center / space-between / space-around
align-items 交叉轴对齐 stretch / center / flex-start
flex-wrap 是否换行 nowrap（默认）/ wrap
flex-direction 主轴方向 row（横向）/ column（纵向）
gap 子元素间距 10px 等（不再需要 margin 逐个加）

关键概念解释

  • 主轴：决定元素排成一行（默认水平，从左到右）
  • 交叉轴：与主轴垂直的方向（默认垂直，从上到下）
  • space-around：主轴上每个元素两侧留等量空白，所以元素之间的间隔是边缘间隔的 2 倍
  • stretch：align-items 的默认值，元素在交叉轴上自动拉伸，撑满整个容器高度

3.3 Grid 网格布局

什么是 Grid？

Grid 是二维布局模型，同时控制行和列。

基础用法

常用属性

  • grid-template-columns：定义列
  • grid-template-rows：定义行
  • gap：间距
  • grid-area / grid-column：控制元素占据的位置和跨度

fr 单位

fr 是网格的”份”单位：

  • 1fr 1fr 2fr 表示按 1:1:2 分宽
  • auto-fit + minmax(200px, 1fr) 组合可以做出自动换行的响应式网格

3.4 常用单位

单位 说明 适用场景
px 固定像素 精确控制的场景

什么是视口？

视口就是浏览器里显示网页的”窗口”。

  • 电脑视口大，手机视口小
  • CSS 通过判断视口宽度，来决定网页是横着排还是竖着排

防止溢出

min-width / max-width：限制弹性元素的可变范围，是响应式的必备组合。

五、伪类、伪元素与动画

5.1 伪类

伪类描述元素的特殊状态，写法是 选择器:伪类。

状态伪类

  • :hover：悬停
  • :active：按下
  • :focus：聚焦
  • :visited：已访问（受浏览器隐私限制，只能改颜色类属性）

结构伪类

  • :first-child：第一个子元素
  • :last-child：最后一个

六、JavaScript 基础

6.1 什么是 JavaScript

JavaScript（简称 JS）是运行在浏览器里的编程语言，用来让网页「动起来」：点击按钮弹提示、轮播图切换、表单校验、请求后端数据都是它的工作。

三个关键点：

  1. HTML（结构）+ CSS（样式）+ JavaScript（行为）= 完整网页
  2. JS 由 ECMAScript 标准定义，ES6 / ES2015 是重要版本（带来 let、const、箭头函数、Promise 等）
  3. 现在的 JS 也可以脱离浏览器运行（如 Node.js 写后端）

📌 简单理解：HTML 是骨架，CSS 是衣服，JS 是肌肉和神经——让网页能响应、能交互。

6.2 变量与数据类型

变量声明

区别：

  • let：块级作用域，可重新赋值（推荐）
  • const：块级作用域，不能重新赋值（推荐用于常量）
  • var：函数作用域，有变量提升问题（不推荐）

原则： 默认用 const，确实需要重新赋值时才用 let，避免用 var。

箭头函数的特点：

  1. 简写语法：更简洁，适合回调函数
  2. 继承外层 this：不会动态变化，不用再写 const self = this
  3. 不能用作构造函数：不能 new
  4. 没有 arguments 对象：需要用剩余参数 ...args

📌 使用场景：回调函数、事件处理、数组方法（map/filter/reduce）优先用箭头函数。

  • 全局作用域：整个文件可访问
  • 函数作用域：函数内部可访问（var）
  • 块级作用域：{} 内可访问（let/const）

闭包：函数可以记住并访问它定义时的作用域，即使外层函数已经执行完。

📌 闭包会一直持有外部变量，用完后及时释放引用避免内存占用。

6.8 DOM 与事件

什么是 DOM？

DOM 是浏览器把 HTML 解析成的对象树，JS 通过操作 DOM 来改变页面。

📌 简单说：DOM 就是 JS 和网页之间的桥梁。网页加载后，浏览器把 HTML 标签变成一个个对象，连成树状结构，JS 通过这些对象就能找到元素、修改内容、改变样式。

为什么用树结构？

  1. HTML 标签是嵌套的父子关系，树最适合表达层级
  2. 方便浏览器遍历解析、JS 查找操作元素
  3. 方便后续页面渲染

浏览器解析流程：

  1. HTML → 解析成 DOM 树（节点对象）
  2. CSS → 解析成 CSSOM 树（样式对象模型）
  3. 合并生成渲染树，用来绘制页面

📌 最佳实践：尽量用 class 切换配合 CSS 做样式变化，比一行行改 style 更易维护。

⚠️ 修改 DOM 会触发重排（Reflow）和重绘（Repaint），大量操作时可以用 DocumentFragment 减少次数。
