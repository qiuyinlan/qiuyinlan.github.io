CSS 伪元素演示

CSS 伪元素演示

::before / ::after / ::first-letter / ::first-line / ::selection / ::placeholder

一、::before / ::after：在元素内部"凭空"生成内容

1. 最基础：content 是开关

没有 content，伪元素不会出现；哪怕 content:"" 也能让盒子生效

我是被前后包裹的原内容

.gen::before { content: "【前置】"; }
.gen::after  { content: "【后置】"; }

2. 装饰小圆点（自定义列表符号）

用 ::before 画一个圆点，替掉默认的 list-style

  • 第一项
  • 第二项
  • 第三项
li::before {
  content: "";
  position: absolute; left: 0; top: 14px;
  width: 10px; height: 10px; border-radius: 50%;
  background: #3498db;
}

3. 气泡箭头（纯 CSS 三角）

::after 用透明边框拼出朝下的小三角，无需图片

这是一个带箭头的气泡提示框，箭头由 ::after 生成。
.bubble::after {
  content: "";
  position: absolute; left: 28px; bottom: -10px;
  border: 10px solid transparent;
  border-top-color: #0984e3; border-bottom: none;
}

4. 卡片渐变角标（NEW 丝带）

::before 定位到右上角并旋转 45 度，做出斜挂的角标

新上线的活动卡片
.card-badge { position: relative; overflow: hidden; }
.card-badge::before {
  content: "NEW";
  position: absolute; top: 16px; right: -34px;
  transform: rotate(45deg);
  background: linear-gradient(135deg, #ff6b6b, #feca57);
}

5. 图标与文字之间的分割线

::after 撑满剩余空间画一条渐隐横线

[图标] 热门推荐
.icon-text { display: flex; align-items: center; }
.icon-text::after {
  content: ""; flex: 1; height: 1px; margin-left: 12px;
  background: linear-gradient(90deg, #b2bec3, transparent);
}

6. 清除浮动（经典 clearfix）

对比：上面父盒子没清除浮动会塌陷；下面用 ::after 清除后高度被正确撑开

二、::first-letter / ::first-line / ::selection / ::placeholder

1. ::first-letter 首字母下沉（Drop Cap）

让段落第一个字放大、飘左，像杂志排版

Once upon a time，这是一段用于演示首字母下沉的正文文字。注意开头那个 O 被放大并飘到了左侧，其余文字环绕着它继续排版，效果类似杂志的栏首大写。

p::first-letter {
  float: left; font-size: 46px; line-height: .8;
  padding: 4px 8px 0 0; color: #e74c3c; font-weight: bold;
}

2. ::first-line 首行样式

只把第一段文字加粗变紫放大，其它行不变

这是首行文字，会被加粗并放大、变紫色。这是第二行及之后的普通正文，保持默认样式，用来对比首行与非首行的差异，行宽变化时首行范围会自动跟随。

p::first-line { color: #8e44ad; font-weight: bold; font-size: 17px; }

3. ::selection 选中文字样式

用鼠标框选下面这句话，选中底色会变成黄色、字变橙

试着用鼠标拖动选中这段文字，观察 ::selection 的自定义高亮。

p::selection { background: #fdcb6e; color: #d35400; }

4. ::placeholder 输入框提示文字

光标进来前显示的提示字，可改颜色、斜体（只有部分属性可改）

input::placeholder { color: #e74c3c; font-style: italic; }
要点速记：伪元素用双冒号 ::，它不是选中真实 DOM，而是"凭空"插入一个在 HTML 里看不到的盒子。::before / ::after 必须写 content 才显示（哪怕是空串）；::first-letter / ::first-line 只作用于块级文本容器；::selection 只在文字被选中时生效；::placeholder 出于规范限制只能改少量样式属性。
